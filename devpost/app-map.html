A small guide to the working proof of concept

LibreY app map

A text-led social feed where posts point to their exact passage in public-domain books. The feed, source reader, and reader preferences are bundled or stored locally; no server or live AI service is involved.

One action, from signal to feed

Opening a post adds a local signal for its book's subject. The next For You build uses topic affinity, keeps a discovery slot, and avoids repeating a book within three cards.

To change this, start here

  • Feed ranking rules: FeedRanker.rank in lib/data/feed_ranker.dart; update the matching checks in test/feed_ranker_test.dart.
  • Bundled books and posts: the JSON files under assets/data/; source grounding is checked in test/demo_content_test.dart.
  • Post details and poll/quiz/debate controls: lib/screens/post_detail_screen.dart and the post interaction widget tests.
  • Responsive navigation: lib/screens/feed_screen.dart and test/feed_responsive_test.dart.

A practice to reuse

The PRD defines observable feed behavior; feed_ranker_test.dart turns it into checks for selected interests, engagement, skips, discovery, and diversity. On another project, anchor an agent's implementation to observable criteria and tests rather than trusting that code merely looks plausible.

Run it again

From the repository root, run flutter pub get, then flutter run -d web-server --web-port 7357 and open http://localhost:7357. The app-map works offline and has no script or network dependencies.
